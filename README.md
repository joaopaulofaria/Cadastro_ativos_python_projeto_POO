# Sistema de Gerenciamento de Ativos de TI

Sistema desenvolvido em Python para cadastro e gerenciamento de ativos de TI e suas vulnerabilidades, desenvolvido para a disciplina de Cibersegurança da Universidade Federal de Uberlândia.

## Funcionalidades

- Cadastrar ativos de TI
- Consultar ativos cadastrados
- Atualizar dados de um ativo
- Deletar ativos
- Cadastrar vulnerabilidades associadas a um ativo

## Tipos de ativos suportados

- Notebook
- Servidor
- Roteador
- Software
- Aplicação Web
- Banco de Dados
- Impressora
- Estação de Trabalho

## Tecnologias utilizadas

- Python 3.12
- Docker
- JSON
